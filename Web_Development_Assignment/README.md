# Web Development Assignment (P1–P13)

This folder contains all 13 practical assignments arranged into three modules.

## How to use
1. Extract this ZIP file.
2. Open the `Web_Development_Assignment` folder in Visual Studio Code.
3. For HTML/CSS practicals, open the required P-folder and open `index.html` in a browser.
4. You can also use the VS Code Live Server extension if it is installed.
5. Module 1 contains Git and terminal practice instructions. Follow the README inside each practical folder.

Each practical is kept separate so that files from one assignment do not interfere with another.

## Folder structure
- Module 1: P1–P4 — Terminal, Git and GitHub
- Module 2: P5–P9 — HTML and CSS foundations
- Module 3: P10–P13 — CSS layout systems

The designs intentionally use simple layouts, readable text and basic colours.
