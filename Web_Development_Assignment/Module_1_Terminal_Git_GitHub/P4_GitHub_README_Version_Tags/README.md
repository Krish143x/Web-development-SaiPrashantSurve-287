# P4: GitHub README and version tags

## Aim
Write project information in a README file and create a version tag.

## Useful Git commands
```bash
git status
git add README.md
git commit -m "Add project README"
git tag v1.0
git tag
git push origin main
git push origin v1.0
```

## What to include in your project README
- Project name
- Short description
- Technologies used
- How to run the project
- Author name

A Git tag such as `v1.0` marks a particular version of your project.
