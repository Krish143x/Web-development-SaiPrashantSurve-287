# P1: Project folder and terminal navigation

## Aim
Create a project folder and practise moving between folders using the terminal.

## Steps
1. Open VS Code.
2. Open Terminal → New Terminal.
3. Move to a location where you want to save your work.
4. Create and enter the project folder.

## Commands
```bash
mkdir my-portfolio
cd my-portfolio
mkdir images css
touch index.html
ls
pwd
```

## Meaning
- `mkdir` creates a folder.
- `cd` enters a folder.
- `touch` creates a file.
- `ls` displays files and folders.
- `pwd` displays the current folder location.

On Windows PowerShell, `New-Item index.html -ItemType File` can be used instead of `touch index.html`.
