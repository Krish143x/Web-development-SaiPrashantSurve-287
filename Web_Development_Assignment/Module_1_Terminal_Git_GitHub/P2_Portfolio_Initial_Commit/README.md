# P2: Portfolio repo with an initial commit

## Aim
Create a simple portfolio project, initialise Git and make the first commit.

## Steps
1. Open this folder in VS Code.
2. Open the terminal in this folder.
3. Run the commands below.

## Git commands
```bash
git init
git status
git add .
git commit -m "Initial portfolio commit"
```

To connect a GitHub repository, create an empty repository on GitHub and use its repository URL:

```bash
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_REPOSITORY_URL` with your own GitHub repository URL.
